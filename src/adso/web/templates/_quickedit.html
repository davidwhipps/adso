{# Hover/focus-revealed pencil that opens a quick-edit popover of the local fields for `book`. The panel body is loaded lazily the first time the pencil is opened (so a list of hundreds of books doesn't render thousands of hidden controls up front); Alpine toggles visibility thereafter. `scope` (shelf|table) namespaces the loaded controls so the same book's shelf and table popovers never share element ids. Reveal is driven by the enclosing `.group` item — see .quick-edit-trigger in styles/input.css. The panel is position:fixed and placed by `place()` so it stays on screen from any grid column (a purely CSS anchor would overflow the viewport for the left/right-edge cards and on the 2-column mobile grid). Expects `book`, `scope`. #}
